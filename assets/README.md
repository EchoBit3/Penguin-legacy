# Asset boundary

F0 no contiene arte, musica, fuentes ni otros recursos de terceros. Esta
carpeta queda reservada para assets propios o con licencia verificada.

Los recursos de referencia privada viven fuera del repositorio en
`assets-private/`, que esta excluida por `.gitignore`. No se copia contenido
privado a esta carpeta sin completar la ficha de procedencia definida en
`docs/10-procedencia-de-assets.md`.
